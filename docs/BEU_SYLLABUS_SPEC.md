# BEU 5-Tier Syllabus & Curriculum Hierarchy Specification

## Data Model Contract
Every subject in Bihar Engineering University is organized under a strict 5-tier tree hierarchy:
```
University (BEU Patna)
  └── Branch (e.g., Computer Science & Engineering - Code: 101)
        └── Semester (e.g., Semester 5)
              └── Subject (e.g., Database Management Systems - Code: PCC-CS501)
                    └── Unit (e.g., Unit 1: Relational Model & SQL)
                          └── Topic (e.g., B+ Trees Indexing & Normalization)
```

## Universal Branch Coverage
The platform supports all 34 official BEU branches including CSE, AI/ML, Cyber Security, Data Science, ECE, EEE, Mechanical, Civil, Chemical, and Mining Engineering.
