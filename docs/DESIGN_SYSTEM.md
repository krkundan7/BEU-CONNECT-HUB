# BEU Connect Hub - Design System & UI Tokens

## Color Hierarchy
- **Primary Accent**: Emerald Cyan (`#00D26A` / `#059669`)
- **Secondary Accent**: Electric Indigo (`#6366F1`)
- **Dark Surface**: Obsidian Jet (`#0B0F17`, `#111827`)
- **Glassmorphism**: `rgba(17, 24, 39, 0.75)` with `backdrop-filter: blur(12px)`

## Typography
- **Headings**: Outfit, sans-serif (700 / 800 weight)
- **Body & Code**: Inter & JetBrains Mono
