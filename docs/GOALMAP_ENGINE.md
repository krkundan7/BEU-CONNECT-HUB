# GoalMap Career Discovery Engine Specification

## Algorithm Architecture
The GoalMap GPS algorithm analyzes 16 distinct engineering career tracks (Fullstack, AI/ML, Cloud DevOps, Embedded IoT, Gate, Public Sector, Data Engineering, etc.):
1. Ingests current semester and branch.
2. Extracts completed syllabus units.
3. Computes skill gaps against industry requirements.
4. Generates prioritized 30-day milestone sprint.
